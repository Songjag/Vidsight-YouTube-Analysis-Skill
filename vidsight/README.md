# Vidsight YouTube Skill

This folder contains the portable `vidsight-youtube-skill` agent skill.

## Installation

Copy this folder to one of the supported skill locations:

```text
.agents/skills/vidsight-youtube-skill/
.github/skills/vidsight-youtube-skill/
.claude/skills/vidsight-youtube-skill/
```

The folder must contain:

```text
vidsight-youtube-skill/
└── SKILL.md
```

The skill is designed for Vidsight's current MCP tools, CLI workflow, sampled
frame evidence, timestamped transcript evidence, provider policy, and privacy
rules.
